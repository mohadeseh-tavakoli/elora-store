# ÉLORA (الورا)
Persian RTL luxury hijab/scarf e-commerce prototype (React via CDN, single HTML file).

- `index.html` – ready to open in a browser
- `src/template.html` – editable source (images are injected at build time)
- `build.py` – `python3 build.py` regenerates index.html
- `assets/reference-crops/` – low-res crops from the design reference, temporary; replace with the original photos

Planned: React + TypeScript + Tailwind project, WooCommerce-ready data layer.
